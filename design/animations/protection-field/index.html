03B / FUNCTIONAL QUARTER EFFECTS

Protection field

A faceted protection field occupies the two dark quarters while the normal rings remain.

PRIORITYSecondary
RING FAMILYStandard
SOURCEEngine catalog · shield effect
01 / MEANING AND BOUNDARY

What this animation is for.

Protection field is the preferred shielding animation. Unlike Shield array, it does not turn the orbit into specialized emitters, so the message remains minimal and system-oriented.

USE IT WHEN

The visual earns its place.

  • Protection, resilience or guarded network space is central
  • A network page needs a functional shield effect
  • You need shielding without a specialized ring
DO NOT USE IT WHEN

A simpler choice is clearer.

  • The page only needs a neutral network body
  • The emitter structure itself is part of the explanation
02 / EXACT CONFIGURATION

Configure. Do not rebuild.

This page mounts the supplied engine declaratively. The page adds documentation and layout only; it does not contain animation geometry.

<script src="drayker-mark.js"></script>

<svg data-drayker
     data-body="grid"
     data-rings="hairline"
     data-wedge="shield"
     data-accent="#3FA9FF"
     data-shadow="1">
</svg>
body=gridSelects the existing grid body renderer.
rings=hairlineUses the standard orbital rings.
wedge=shieldUses the existing shield effect inside the shadow.
accent=#3FA9FFUses an existing published scope color.
shadow=1Keeps the two-quarter shadow fully opaque.
03 / SOURCE AND INTEGRITY

One engine remains authoritative.

The renderer loaded here is the same supplied drayker-mark.js verified by the repository integrity check. Extend the registered body, ring or quarter-effect catalogs only when an existing configuration cannot express the requirement.
