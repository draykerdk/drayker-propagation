01D / UNIVERSAL · IDENTITY BASELINE

Core orbit

The baseline living Drayker mark. It keeps the body quiet, the shadow opaque and the orbital structure in its standard hairline form.

PRIORITYPrimary
RING FAMILYStandard
SOURCEEngine catalog · plain + hairline
01 / MEANING AND BOUNDARY

What this animation is for.

Use Core orbit when the animation should communicate Drayker itself rather than a specific subsystem or machine. The dark two-quarter shadow carries the mark; the rings respond to the viewer without becoming the subject.

USE IT WHEN

The visual earns its place.

  • A general Drayker introduction or transition
  • A page needs motion but not a project-specific metaphor
  • You need the safest animated starting point
DO NOT USE IT WHEN

A simpler choice is clearer.

  • A static production mark is sufficient
  • A specific body or quarter effect is essential to the explanation
02 / EXACT CONFIGURATION

Configure. Do not rebuild.

This page mounts the supplied engine declaratively. The page adds documentation and layout only; it does not contain animation geometry.

<script src="drayker-mark.js"></script>

<svg data-drayker
     data-body="plain"
     data-rings="hairline"
     data-wedge="none"
     data-accent="#FF5500"
     data-shadow="1">
</svg>
body=plainSelects the existing plain body renderer.
rings=hairlineUses the standard orbital rings.
wedge=noneAdds no extra quarter effect; the dark structural shadow remains.
accent=#FF5500Uses an existing published scope color.
shadow=1Keeps the two-quarter shadow fully opaque.
03 / SOURCE AND INTEGRITY

One engine remains authoritative.

The renderer loaded here is the same supplied drayker-mark.js verified by the repository integrity check. Extend the registered body, ring or quarter-effect catalogs only when an existing configuration cannot express the requirement.
