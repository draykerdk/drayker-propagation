03C / FUNCTIONAL QUARTER EFFECTS

Terraform field

Measured plots appear inside the two shadowed quarters beneath the standard orbit.

PRIORITYSecondary
RING FAMILYStandard
SOURCEEngine catalog · terraform effect
01 / MEANING AND BOUNDARY

What this animation is for.

Terraform field represents transformation, measured intervention and a body being rewritten. The standard ring keeps the scene conceptual rather than architectural.

USE IT WHEN

The visual earns its place.

  • Transformation or staged intervention is the subject
  • A process changes only a defined portion of a system
  • Measured plots clarify the narrative
DO NOT USE IT WHEN

A simpler choice is clearer.

  • The page is about general construction rather than transformation
  • A hull physically doing the work must be shown
02 / EXACT CONFIGURATION

Configure. Do not rebuild.

This page mounts the supplied engine declaratively. The page adds documentation and layout only; it does not contain animation geometry.

<script src="drayker-mark.js"></script>

<svg data-drayker
     data-body="plain"
     data-rings="hairline"
     data-wedge="terraform"
     data-accent="#FF5500"
     data-shadow="1">
</svg>
body=plainSelects the existing plain body renderer.
rings=hairlineUses the standard orbital rings.
wedge=terraformUses the existing terraform effect inside the shadow.
accent=#FF5500Uses an existing published scope color.
shadow=1Keeps the two-quarter shadow fully opaque.
03 / SOURCE AND INTEGRITY

One engine remains authoritative.

The renderer loaded here is the same supplied drayker-mark.js verified by the repository integrity check. Extend the registered body, ring or quarter-effect catalogs only when an existing configuration cannot express the requirement.
