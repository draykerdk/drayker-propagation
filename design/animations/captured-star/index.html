Captured star

Collector rings surround a radiant body and make stellar extraction unmistakable.

PRIORITYExample only
RING FAMILYCustom collector
SOURCEOriginal Logo Variations · 13f
01 / MEANING AND BOUNDARY

What this example demonstrates.

Captured star demonstrates a highly explicit custom narrative: stellar body plus collector apparatus. It is intentionally rare and should be reserved for content specifically about large-scale energy capture.

USE IT WHEN

The visual earns its place.

  • Stellar energy collection is the direct subject
  • The corona and collector need to interact
  • You need the original 13f configuration
DO NOT USE IT WHEN

A simpler choice is clearer.

  • Energy is only a metaphor
  • A standard Stellar body carries enough meaning
02 / EXACT CONFIGURATION

Configure. Do not rebuild.

This page mounts the supplied engine declaratively. The page adds documentation and layout only; it does not contain animation geometry.

<script src="drayker-mark.js"></script>

<svg data-drayker
     data-body="star"
     data-rings="collector"
     data-wedge="extract"
     data-accent="#FF5500">
</svg>
body=starSelects the existing star body renderer.
rings=collectorUses the specialized collector orbital structure.
wedge=extractUses the existing extract effect inside the shadow.
accent=#FF5500Uses an existing published scope color.
03 / SOURCE AND INTEGRITY

One engine remains authoritative.

The renderer loaded here is the same supplied drayker-mark.js verified by the repository integrity check. Extend the registered body, ring or quarter-effect catalogs only when an existing configuration cannot express the requirement.
