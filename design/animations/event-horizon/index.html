Event horizon

A wide hull and extraction effect operate against a black body and photon horizon.

PRIORITYExample only

SOURCEOriginal Logo Variations · 13g
01 / MEANING AND BOUNDARY

What this example demonstrates.

Event horizon is the catalog’s most extreme customization example: black body, heavy hull and extraction field. It must not replace the more broadly useful Black Hole symbol.

USE IT WHEN

The visual earns its place.

  • An event horizon or extreme extraction is explicitly discussed
  • A research narrative requires the strongest visual state
  • You need the original 13g configuration
DO NOT USE IT WHEN

A simpler choice is clearer.

  • The subject can be explained by Void body
  • A restrained or broadly reusable animation is required
02 / EXACT CONFIGURATION

Configure. Do not rebuild.

This page mounts the supplied engine declaratively. The page adds documentation and layout only; it does not contain animation geometry.

<script src="drayker-mark.js"></script>

<svg data-drayker
     data-body="voidBody"
     data-rings="hull"
     data-wedge="extract"
     data-accent="#FF5500"
     data-stars="1">
</svg>
body=voidBodySelects the existing voidBody body renderer.
rings=hullUses the specialized hull orbital structure.
wedge=extractUses the existing extract effect inside the shadow.
accent=#FF5500Uses an existing published scope color.
stars=1Enables the engine’s existing sparse background field.
03 / SOURCE AND INTEGRITY
