02C / STANDARD BODY · NORMAL RINGS

Woven sphere

Two woven directions move across a spherical body while the standard orbit remains unchanged.

PRIORITYPrimary
RING FAMILYStandard
SOURCEEngine catalog · weave + hairline
01 / MEANING AND BOUNDARY

What this animation is for.

Woven sphere expresses interdependence, federation and reciprocal construction. It is still a primary-family animation because the ring does not become a separate machine.

USE IT WHEN

The visual earns its place.

  • Federated relationships or interdependence are the subject
  • Several paths must read as one body
  • A cooperative system needs a restrained living illustration
DO NOT USE IT WHEN

A simpler choice is clearer.

  • A literal network topology is clearer
  • Industrial infrastructure is the actual subject
02 / EXACT CONFIGURATION

Configure. Do not rebuild.

This page mounts the supplied engine declaratively. The page adds documentation and layout only; it does not contain animation geometry.

<script src="drayker-mark.js"></script>

<svg data-drayker
     data-body="weave"
     data-rings="hairline"
     data-wedge="none"
     data-accent="#FF5500"
     data-shadow="1">

body=weaveSelects the existing weave body renderer.
rings=hairlineUses the standard orbital rings.
wedge=noneAdds no extra quarter effect; the dark structural shadow remains.
accent=#FF5500Uses an existing published scope color.
shadow=1Keeps the two-quarter shadow fully opaque.
