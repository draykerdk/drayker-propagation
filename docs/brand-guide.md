# Drayker Propagation Brand Guide

Use this kit to make source-led material that is recognisably Drayker and easy to trust.

## The principle

The job is to clarify, not to amplify at any cost. Start with a published primary source, explain one idea accurately, and give the reader a useful next place to go.

## Use the official files

The complete pack is in [`../assets/brand/logo/`](../assets/brand/logo/).

| Need | Use |
| --- | --- |
| Regular symbol, 20 px and above | `drayker-marca.svg` |
| Mark on a dark surface | `escuro/drayker-marca.svg` |
| Small favicon only | `drayker-favicon.svg` or `drayker-icone.svg` |
| Name plus mark | `assinatura/drayker-horizontal.svg` or `assinatura/drayker-horizontal-branco.svg` |
| One-colour print | a file from `mono/` |
| Scope-specific material | a matching file from `escopo/` |

## Mark rules

- Keep the supplied proportions and clear space.
- Use the dark variants on dark backgrounds and the standard variants on light backgrounds.
- Keep the globe colour and the ring/shadow treatment supplied by the official file.
- Do not stretch, rotate, mirror, recolour, add a glow, add a gradient, redraw, or place the colour mark directly on a busy photo.
- Use the `mono/drayker-vazado-*` files when a one-colour mark must sit over photography or a textured surface.

## Type and colour

- **Archivo** is the display and brand face. Use 600 for the name and titles, 500 for technical labels, and 400 for body copy.
- **JetBrains Mono** is reserved for compact labels, source notes and utility information.
- Core tokens: canvas `#08080A`, surface `#0C0C0F`, border `#18181E`, text `#EDECF0`, muted `#8585A0`, accent `#FF5500`.

## Write responsibly

- Link people to the source that supports the statement.
- Distinguish what is published, proposed and open.
- Do not state that a system, product or governance mechanism is operational unless the public source says so.
- Do not imply endorsement, investment advice, guarantees or artificial scarcity.
- Invite questions and contribution. Do not pressure a decision.

## A quick pre-publish check

1. Is the message understandable without insider vocabulary?
2. Does it cite or link to a primary source?
3. Does the claim match the source's current language and scope?
4. Does the mark use an unedited official asset?
5. Does the reader have a clear, honest next step?

If any answer is no, revise before sharing.
